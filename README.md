# Groundwater Quality Analysis in India (2024)

## About the Project

This project is a Data Visualization case study focused on analyzing groundwater quality across India using data from the Central Ground Water Board (CGWB).

The study investigates the distribution of major groundwater contaminants, identifies regional contamination patterns, compares pre-monsoon and post-monsoon observations, and presents findings through interactive visualizations and dashboards.

## Dataset

- **Source:** Central Ground Water Board (CGWB)
- **Year:** 2024
- **Raw Dataset:** 15,189 records and 36 columns
- **Cleaned Dataset:** 15,185 records and 42 columns
- **Geographical Coverage:** States and Union Territories in India

## Parameters Analyzed

1. Nitrate (NO3)
2. Fluoride (F)
3. Arsenic (As)
4. Iron (Fe)
5. Uranium (U)
6. Total Dissolved Solids (TDS)

## Objectives

- Analyze groundwater quality across Indian states.
- Identify groundwater contamination hotspots.
- Examine state-wise contaminant exceedance rates.
- Compare pre-monsoon and post-monsoon groundwater quality.
- Study relationships between groundwater quality parameters.
- Visualize contamination patterns through interactive dashboards.


## Visualizations

The project includes 13 visualizations covering:

- Contaminant exceedance rates
- State-wise contamination heatmap
- Nitrate distribution
- Fluoride distribution across states
- Nitrate and electrical conductivity relationship
- Seasonal comparison
- Geographical contamination mapping
- Paired-station seasonal comparison
- Multiple contaminant exceedances
- Parameter correlation analysis
- Piper diagram for groundwater classification
- Interactive station mapping
- Interactive state ranking
